## Deterministic certificate and independent checks
Input: `candidates/calderbank_fishburn_236.txt` (the already verified 236-point published witness). The script first checks all 27,730 point pairs using both `verify_capset.verify` and an independent integer base-3 arithmetic implementation. Its first two 6D slices `H,H'` each have 112 points, and their third-slice cross-sum blocker support `Z=-(H+H')` has exactly 717 points; 12 holes remain. For `z in Z`, let `B[z,y]=1` when `-z-y in H`, `y in H'`. Exact row-degree histogram:

`{11:32,15:192,16:160,18:240,24:60,30:32,32:1}`.

Normalize each row by its positive degree `r(z)`, so `T[z,y]=B[z,y]/r(z)`, `T*1_112=1_717`. With `L=lcm(r(z))=15840`, form the **integer** Gram `G=(LT)^T(LT)` (112×112). Put `lambda=185130000 = (425/576)L²`, and let `D` be the 112×111 integer matrix with columns `e_(i+1)-e_0`. Compute `K=D^T(lambda I-G)D` (111×111, exact integers). Every `v in 1_112^perp` equals `Da` for some real `a`, so `K >= 0` is exactly the desired spectral bound.

The independent exact **symmetric fraction-free Bareiss/Schur elimination** verifies 107 strictly positive pivots, followed by an identically zero 4×4 trailing block. It checks every integer division has zero remainder and uses only symmetric row/column permutations (88 swaps). Thus `K` is positive semidefinite of rank 107 and nullity 4. A second, independent Gaussian-elimination calculation modulo the prime 1,000,000,007 finds rank 107, corroborating rank. The first three integer pivots are `218773520`, `35896389789892800`, `5235453033084605519104000`. The equality eigenspace has dimension 4 on `1^perp`; the largest restricted squared singular value is **exactly 425/576**, not an approximate SVD observation.

## Mathematical consequence (fixed H,H' only)
Suppose `m >= 1` previously blocked third-slice points `z in Z` are unlocked by deleting `d` points from the fixed second slice `H'`, while the first slice `H` stays fixed. Let `v` indicate these m rows. Every row of `T` sums to 1 and is supported entirely on the deleted columns, so `w=T^T v` is supported on at most d coordinates and `sum_y w_y=m`. Cauchy gives `||w||² >= m²/d`. Decomposing `v` and `w` into constant and orthogonal components, the certified spectral bound gives
`||w||² <= m²/112 + (425/576)m`.
Therefore
`d >= ceil(64512*m/(576*m+47600))`.
In particular `d >= m+1` for `1 <= m <= 29` and `d >= m` for `1 <= m <= 32`. This is a **restricted deletion obstruction**, not a global proof about arbitrary 237-caps. It also does not constrain simultaneously deleting arbitrary points from both first and second slices.
