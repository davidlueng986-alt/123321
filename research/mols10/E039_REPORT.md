## Exact mathematical method
For a fixed valid k-row partial triple, enumerate allowed remaining placements (column,a,b,c) and six classes of required demands: P_AB,P_AC,P_BC and C_A,C_B,C_C (missing ordered pairs and missing column-symbol occurrences). Any completion gives a nonnegative integer vector x with Ax=1. Thus for **any** selection K of 1–6 resource classes, A_K x=1, x>=0 is necessary. A verified integer vector y with sum(y)>0 and y^T A_K[:,t]<=0 for every candidate placement t proves **only that fixed prefix** cannot extend: 0<sum(y)=y^T A_K x<=0. Numerical HiGHS is used to propose y; a separate JavaScript implementation rebuilds every candidate and verifies all inequalities using integer arithmetic.
