# E003–E005: independent pair screening, sampled mate landscape, and exact two-symbol trades

**Research date:** 2026-11-02. **Scope:** computational results for specified published order-10 pairs and a bounded heuristic sample. **Global 3-MOLS(10) status: OPEN.** These results are not claimed to be novel mathematical literature.

## E003 — A third historical orthogonal pair (Bose–Shrikhande–Parker)

Source: Peter W. M. John, *Statistical Design and Analysis of Experiments*, p.114 (1971; SIAM 1998), citing Bose–Shrikhande–Parker (1960). Original 10×10 array of paired digits reproduced as `parker_pair.json`. PDF: https://sites.ualberta.ca/~dwiens/stat568/misc%20resources/PWJohn.pdf .

Exact independent Latin check: A and B each have 10 distinct symbols in every row and column; 100/100 pairs across their cells.

Canonical SHA256 of Python `json.dumps([A,B], separators=(',',':'))`:
`1fea184b868434e5ecc9d9acb27061d0429850b5bc3e257ff31158a7bd632dfe`.

Two independent complete common-transversal enumerators:
1. All `10!` column permutations checked against both symbol constraints (existing `transversals.py`).
2. Bitmask depth-first search, recording the complete prefix depth profile (new `parker_frontier.py`).

Results: exactly **0 common transversals**. DFS depth profile over rows 0..9, including the empty prefix:

`[1, 10, 70, 329, 1046, 1983, 2233, 1471, 318, 21, 0]`.

At depth 9 there are **21** surviving row-to-column partial injections; all 21 are blocked at the one remaining cell by BOTH A-symbol and B-symbol conflicts. The explicit 21 prefixes are generated by `python parker_frontier.py` and checked by `test_parker_frontier.py`.

Therefore this **fixed** pair has no possible third orthogonal mate, as any symbol class of a third square would necessarily be a common transversal. No universal nonexistence result follows.

This pair cannot be paratopic to the Egan–Wanless (A,B) or (A,C) pairs under the usual OA four-coordinate relabeling/permutation group: number of common transversals is invariant under coordinate and symbol permutations; the other two pairs have counts 14 and 7. This establishes inequivalence **between these explicit witnesses**, not a newly discovered equivalence class in the literature.

## E003b — Scalable exact-cover backend

`exact_cover.py` solves the selected fixed-pair extension as an exact cell cover by pairwise disjoint common transversals, branching on the most-constrained uncovered cell. An interrupted search returns `UNKNOWN_BUDGET`, never UNSAT. A complete unsatisfiable search is explicitly scoped `UNSAT_FIXED_PAIR_EXACT`; SAT witnesses are independently replayed by `verify.py`.

Validated: Parker (0 transversals, UNSAT), Egan AB (14, UNSAT), Egan AC (7, UNSAT), and GF(4) positive case (4 disjoint transversals, SAT, 16/16/16).

## E004 — Randomized but deterministic orthogonal-mate sampling

For the specific published Egan–Wanless Latin square A, enumerate **all 1080** single-A transversals. Each seed permutes these 1080 candidates using `random.Random(seed)` and searches for an exact partition into ten transversals, thereby constructing a mathematically valid B orthogonal to A. B is canonicalized by independently relabeling its first row to `0..9`. This **is not** a complete enumeration of mates; sampling is biased by the exact-cover branching order.

Experiment: 200 deterministic seeds, `0..199`, as two disjoint blocks (0..79 and 80..199).
- All 200 seeds yielded valid mates; there were **91 distinct first-row-normalized B matrices**, with 109 repeats across those seeds (the within-block duplicate counts and cross-block overlap are handled by union of SHA256 digests).
- Distribution of exact common-transversal counts **among 91 distinct normalized matrices**: `{0:37, 1:28, 2:6, 3:13, 4:3, 6:3, 14:1}`.
- None had full 100-cell common-transversal coverage, so none can extend to a third mate.
- The only 14-transversal sampled B occurs at seed 14 and **exactly equals** the known Egan–Wanless B after first-row symbol normalization. It is not a new witness.
- Source code: `sample_mates.py`; reproduce with `python sample_mates.py --samples 200 --seed-start 0 --output sampling_report.json`.
- A separate 40-seed attempt with Parker's A exceeded the available execution timeout, so its state is `UNKNOWN_TIMEOUT` and cannot be used as negative evidence.

The chance of missing rare extendible pairs is unknown. No statistical bound is claimed for this strongly biased sampler.

## E005 — All two-symbol component-flip neighborhoods of 3 known pairs

Fix an orthogonal pair A,B. Pick each of the 45 symbol pairs p<q of B; restrict to its 20 selected cells; connect cells sharing row, column, or A-symbol. The graph's connected components can be flipped between p and q while preserving all row/column/A constraints. Enumerating all 45 pairs therefore explores the **entire two-symbol component-flip neighborhood**, NOT arbitrary multi-symbol Latin trades.

- Egan–Wanless A,B: all 45 graphs connected, **0** nontrivial proper component flips.
- Egan–Wanless A,C: exactly 3 pairs `(1,8), (2,9), (3,7)`, each with component sizes (14,6). Each flipped neighbor has only **1** A/C' common transversal (baseline: 7).
- Parker A,B: exactly 3 pairs `(7,8), (7,9), (8,9)`, each (14,6); each flipped neighbor still has **0** common transversals.

Reproduce through `two_symbol_trades.py`, `test_two_symbol_trades.py`. These findings support **shifting to 3+ symbol trades or replacing the fixed first square**, rather than repeatedly performing ineffective 2-symbol local changes.

## Status and next experiments

1. Implement more expressive **three-symbol connected trades / exact re-coloring of union of 3–4 symbol classes**, avoiding symmetry duplicates and maintaining pair orthogonality by construction.
2. Change the fixed A to a genuinely different Latin square / original paper pair, but place explicit budget limits on sampling. Parker A is computationally harder for the naive sampler.
3. Seek input pairs having >=10 common transversals AND no uncovered cell. On a qualifying pair, use `exact_cover.py` with bounded search, independent witness checking and auditable negative scope.
4. For any wider enumeration, prove every symmetry reduction, and verify against the published 2026 SAT literature.

External status source: https://www.combinatorics.org/ojs/index.php/eljc/article/view/v33i1p30 . The peer-reviewed result is restricted and does not solve the general existence question.
